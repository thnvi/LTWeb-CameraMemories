**CameraMemories – Camera E-commerce Website**

CameraMemories is a web-based e-commerce application developed using ASP.NET MVC and C#. The project aims to provide users with a convenient and user-friendly platform for browsing and purchasing camera products.

The website includes essential e-commerce functionalities such as product browsing, product categorization, customer registration and login, shopping cart management, order processing, and coupon management. It also provides administrative features for managing products, categories, customers, and orders.

The project integrates SQL Server for database management and uses Entity Framework for data access. The user interface is designed with HTML, CSS, Bootstrap, and JavaScript to ensure a responsive and intuitive shopping experience.

Through this project, I gained practical experience in web application development, database design, MVC architecture, and implementing core e-commerce functionalities. It also helped me improve my problem-solving skills and understanding of software development workflows.
